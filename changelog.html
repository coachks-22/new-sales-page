Changelog

Last updated: August 14, 2026

Public record of what we’re shipping. Grouped for humans; details come from the product git history. This is not every commit — it’s the meaningful product story. We update this as we ship.

August 14, 2026

  • Public TestFlight open for early testers — testflight.apple.com/join/yHbes4j4
  • Onboarding connectors — Strava and Wahoo Connect now use the same real OAuth path as Data & Import (onboarding buttons were stubs)

August 11–13, 2026

  • TestFlight 1.0.0 (build 260811192600) — Intervals.icu workouts now land on the calendar correctly
  • iOS minimum raised to 15.0
  • Heat training notes — lead magnet live at join.veloforge.app/heat for athletes doing serious work in the heat
  • Find layer — public /robots.txt, /sitemap.xml, /llms-full.txt, and join.veloforge.app/llms.txt so humans and AIs can find accurate product truth

August 2026

  • Step-by-step athlete onboarding — new athletes walk one clear screen at a time (not a single long form): profile, goals, availability, then data links. Built to feel simple for first open; existing athletes keep full Athlete / Coach Setup.
  • Dual-primary data sources — pick one training source (Strava / Wahoo / Intervals / manual) for rides, power, session HR, and load, and one recovery source (e.g. Apple Health) for sleep/HRV/RHR — no double-pulling power from two apps. Change sources later on the Athlete tab.
  • Import-first setup — connect a source to pre-fill power curve and HR where possible; manual entry stays as fallback if import isn’t available.
  • Planned workout detail — open a session and it reads more like ride analysis: clearer structure, targets, and purpose (not a flat wall of text)
  • Session Progression Guard — same-family hard days (threshold / tempo / VO₂, etc.) in build weeks must step up in dose, structure, watts, or density — no clone hard sessions; deload, taper, recovery cuts, and hard-volume caps still respected
  • Intervals.icu — personal API integration and Data Import connect flow; OAuth scope rules locked in (SETTINGS:READ, calendar write only without duplicate scopes, import-first / athlete-initiated push)
  • Wahoo — live path confirmed with real-device test (workout uploaded into the app); OAuth reliability + Today/Calendar completion marking
  • FuelSync / Nutrition audit fixes: rebalance, meal delete resurrect bugs, timeline times, inflated targets after long rides
  • Calendar freezes fixed (day open + week navigation)
  • Public FAQ, changelog, and llms.txt on veloforge.app for humans and AI agents
  • TestFlight build path active (e.g. 1.0.0 build 153) for early athletes

July 2026

  • Strava — full connect pipeline, server-side token exchange, sync into calendar + FuelSync, intensity / hard-volume rebalance
  • Coach Forge — full-screen coach chat, plan orchestration, compound requests, live FuelSync + ride context (moved AI surfaces to current Grok models)
  • Training Calendar redesign (Month / Week)
  • Completed ride analysis + Norm Power (Coggan) from power stream
  • Hammerhead (Karoo) OAuth path; Sync Zones from Device; Coach Setup gate for first-run
  • Hybrid Guide Z5 VO2 structure, progressive physiological targets, Momentum cards on live recovery + power history
  • Data & Import upgrades (preview/confirm, Quick Log, Garmin wizard UI)

June 2026

  • Apple Health sleep path; Garmin Connect OAuth/webhook backfill path; Wahoo OAuth + workout sync path
  • FuelSync unification: daily summary, intensity-aware buffers, meal skip/rebalance, during-ride fuel
  • Group ride planning with Z3+ hard-volume trim; deload/taper-aware group ride handling
  • Forge redesigned as AI-first coach command center; weather-aware coaching context
  • Athlete profile + plan persistence across reinstall / re-login; calendar multi-week stability
  • Completed ride analysis with FIT import and execution scoring

May 2026

  • Nutrition depth: meal timing, saved meals library, local parser fallback, quantity editing, KPI polish
  • Coach schedule edit sync across the app
  • Today screen performance / sticky scroll fixes

March–April 2026

  • Core VeloForge app foundations and early coaching / nutrition loops
  • Marketing site + sales landing work; AI agent–friendly demo surfaces
  • Backend model stack iteration (modern LLM providers for coach surfaces)
